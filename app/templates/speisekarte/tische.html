Tisch-QR-Code-Aufkleber drucken

Erzeugt ein PDF mit einem QR-Code-Aufkleber je Tisch. Der Code verlinkt direkt auf die Bestellseite dieses Tisches – kein Login nötig.

Zurück

Beispiel: „Von 1 bis 20" erzeugt Aufkleber für die Tische 1–20 auf mehreren Seiten (6 Aufkleber je A4-Seite). Für einen einzelnen Tisch „Bis" leer lassen.
